# Demo visuale — Teresa Criniti

Landing page statica dimostrativa per una psicologa e psicoterapeuta ad Asti.

## Avvio locale

Aprire `index.html` direttamente oppure avviare un server statico dalla cartella:

```bash
python3 -m http.server 4173
```

La pagina usa file locali per stile, script, logo e immagine principale. La mappa Google richiede una connessione internet.

## Prima della pubblicazione

- sostituire il recapito WhatsApp dimostrativo con il numero reale;
- collegare il modulo a un servizio conforme alla privacy;
- inserire informativa privacy, cookie policy e dati professionali completi;
- verificare con la professionista indirizzo, titoli e testi;
- sostituire o approvare l’immagine AI dello studio.

Questa è una proposta visuale statica, non un sito completo né un sistema di prenotazione operativo.
